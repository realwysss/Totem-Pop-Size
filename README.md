# Totem Pop Size

changes the size of the totem that flies up on your screen when you pop. keeps big pack totems small so they do not cover the fight.

client side fabric mod for minecraft 1.21.11. settings through mod menu (needs [Wysss Library](https://github.com/realwysss/Wysss-Library)):

- **mod on**: turn it off to get the vanilla size back
- **size**: 0% to 100% (default 60%). 100% is vanilla

## download

`totem-pop-size-mc1.21-1.21.11-1.0.0.jar` on the releases page. minecraft 1.21.11, fabric loader 0.16 or newer.
